# Phogit

Public issue tracker for [Phogit](https://phogit.caffeinatedmath.com/), a Git client for iPhone and iPad: clone, edit, commit and push repositories on your device.

- [Report an issue](https://github.com/hjjb-llc/phogit/issues/new/choose)

## Crash reports

If Phogit quits or freezes, iOS saves a report on your device. Open **Settings > About Phogit > Diagnostics**, tap the share button next to the report, and attach the file to a [crash report](https://github.com/hjjb-llc/phogit/issues/new?template=crash.yml). Reports stay on your device until you share one.

Anything you post here is public, so read the report before you submit it. For a private report, email [support@caffeinatedmath.com](mailto:support@caffeinatedmath.com) instead.

Never post a personal access token, password or private key. We'll never ask for them. If you post one by accident, revoke it on your host.
